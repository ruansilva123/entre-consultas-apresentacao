# Entre Consultas · Apresentação

Apresentação do trabalho final de Análise de Sistemas e Requisitos de Software II (UDESC, 2026): **Entre Consultas**, acompanhamento do tratamento da depressão na atenção primária do SUS entre uma consulta e outra.

Equipe: Pedro Henrique Urio dos Santos, Raphael Soares de Almeida, Ruan Carlos da Silva, Vinicius Antonio Jaeger e Vitor Rafael Marcelino.

Protótipo: [entre-consultas-sigma.vercel.app](https://entre-consultas-sigma.vercel.app) · código em [raphael-soares/udesc-entre-consultas](https://github.com/raphael-soares/udesc-entre-consultas)

## Como abrir

É um site estático, sem build: abra o `index.html` no navegador ou publique a raiz do repositório na Vercel (ou no GitHub Pages).

## Protótipo ao vivo

O slide 13 abre o protótipo dentro da apresentação. Clique no quadro para navegar e clique fora dele para voltar a usar as setas. No PDF, esse slide mostra um print no lugar do site.

## Atalhos

| Tecla | O que faz |
|---|---|
| → / Espaço | Próximo slide ou passo |
| ← | Anterior |
| O | Parede com todos os slides |
| N | Notas do apresentador e cronômetro |
| K | Paleta de comandos e busca de slides |
| P | Exportar PDF (um slide por página) |
| F | Tela cheia |
| ? | Todos os atalhos |

Para gerar o PDF sem abrir o navegador: abra `index.html?pdf` e imprima, ou use o Chrome headless com `--print-to-pdf`.

## Estrutura

- `index.html`: todos os slides, o estilo e o motor da apresentação.
- `img/`: diagrama de casos de uso e o print usado no PDF.
